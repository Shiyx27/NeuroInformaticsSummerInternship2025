# NeuroInformaticsSummerInternship2025

Developed a **secure 3-tier federated learning system** using **AES-256 and HMAC-SHA256** for seizure detection across 25 simulated devices, ensuring complete data privacy. Engineered an **ultra-lightweight Pi-optimized CNN (0.54 MB, 140K params)** achieving **<15 ms real-time inference** with **98%+ clinical accuracy**. Implemented a **Byzantine fault-tolerant aggregation mechanism** with dynamic trust scoring, validated on **11K+ EEG samples** for production deployment.
